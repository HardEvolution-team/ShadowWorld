# Shadow World Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **Shadow World** by JaJo_11.

- Original: https://www.9minecraft.net/?p=74576
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.34.0+

This port contains **no original assets**. Put your own copy of the original jar (`shadow_world_mod_1.7.10.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures/sounds from it at runtime.
